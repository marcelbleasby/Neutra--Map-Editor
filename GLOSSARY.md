# Neutra Map Editor

Editor de mapas da plataforma Neutra+ para documentar e operar redes FTTH neutras.
Este glossário fixa o vocabulário do produto; termos ainda em discussão não entram.

## Language

### Organização

**Empresa**:
Organização cadastrada na plataforma, identificada pelo `organization_id`. É a dona de tudo que o editor guarda.
_Avoid_: Organização (na interface), cliente, conta, tenant
