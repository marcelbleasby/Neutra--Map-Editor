# O editor é só do Seller, e o compartilhamento nasce no marketplace

O editor é uma ferramenta do perfil Seller: a Empresa que compra uma porta não entra
nele nem vê a rede. E um compartilhamento de porta não é criado no editor — nasce de
um pedido aceito no marketplace; o editor só indica quais portas atendem aquele
pedido.

Decidimos assim porque a plataforma já tem a regra de que traçados, POPs e CTOs são
privados do Seller, e porque o marketplace já é dono da relação comercial entre as
empresas. Criar compartilhamentos também no editor daria duas respostas para "quem
usa esta porta".

## Consequences

- O editor não tem cadastro de provedores nem visão para o comprador.
- Sem integração com os pedidos do marketplace, o editor só consegue marcar uma porta
  como compartilhada, sem dizer com quem.
